# Шаблон проекта SHIFT+ с AI-Фасилитатором

Скопируйте папку целиком и переименуйте под проект. Правила работы с файлами — в `17_AI_Facilitator.md`, раздел 5.

| Файл | Назначение |
|---|---|
| `STATE.md` | Где проект сейчас и что дальше |
| `FACTS.md` | Реестр утверждений со статусами и источниками |
| `DECISIONS.md` | Журнал решений живых ролей; только дописывается |
| `TASKS.md` | Задания людям между сессиями |
| `artifacts/` | Сданные фреймворки: один файл на фреймворк |
| `inputs/` | Сырой материал: транскрипты, интервью, данные, фото |

Порядок сессии: модель читает `STATE.md`, `DECISIONS.md`, `TASKS.md`; в конце выдаёт их обновления; оператор сохраняет.
